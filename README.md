# Probability Simulator

A simple browser-based classroom probability simulator with seven experiments:

1. Tossing One Coin
2. Tossing Two Coins
3. Rolling One Die
4. Rolling Two Dice
5. Drawing One Ball
6. Drawing Two Balls with Replacement
7. Drawing Two Balls without Replacement

Students choose the number of trials. The simulator pauses after each trial and continues only when **Next Trial** is clicked.

## Run locally

Open `index.html` in a web browser.

## Publish with GitHub Pages

1. Create a new GitHub repository, for example `probability-simulator`.
2. Upload `index.html`, `styles.css`, and `script.js`.
3. Open the repository's **Settings**.
4. Open **Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`.
7. Save.

GitHub will provide a public URL such as:

`https://YOUR-USERNAME.github.io/probability-simulator/`

Students do not need GitHub accounts to open the public GitHub Pages site.
